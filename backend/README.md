# 🚀 Express TypeScript Backend Template

Este es un template base para proyectos backend usando:

- Node.js
- Express
- TypeScript
- Nodemon

---

# 📦 Características

- Servidor Express configurado
- TypeScript listo para producción
- Nodemon para desarrollo
- Estructura base escalable
- Separación de `server` y `index`

---

# 📁 Estructura

```bash
src/
 ├── index.ts   # Entry point del servidor
 └── server.ts  # Configuración de Express
```

# ⚙️ Instalación
```bash
npm install
```

# ▶️ Ejecución en desarrollo
```bash
npm run dev
```

# 🚀 Uso del template
Haz clic en "Use this template"
